## 四格对照结果（160 条冻结题库）

| 配置 | 训练过·原问法 | 训练过·换问法 | 从未训练·原问法 | 从未训练·换问法 | 合计 |
|---|---|---|---|---|---|
| 没微调（裸考） | 5% | 5% | 0% | 0% | 4% |
| 微调过（闭卷） | 5% | 5% | 0% | 0% | 4% |
| 知识库 + 没微调（开卷） | 30% | 17% | 40% | 25% | 26% |
| **知识库 + 微调过（开卷）** | **32%** | **33%** | **40%** | **35%** | **34%** |

> 表里 4 行是**四套系统配置**，列才是作业要的四宫格（训练过/没训练过 × 原问法/换问法）。
> 「没微调」那一行是对照组，用来证明成绩不是"模型本来就会"。

## 三条结论

1. **微调学会了格式与口吻**：带出处率 44/60 → **60/60**；但"完全答对"始终 5%——事实没背进去。
   更值得警惕的是**编造变得更像真的**：不给材料时，它给出的数字格式完整、页码齐全，但数字是错的。
2. **事实靠知识库递进来**：同一道题没材料 8% 命中，给了材料 43%。
3. **微调的价值是"更会用材料"**：同一套检索下，完全答对 20% → 37%、数字命中率 43% → 55%。

和课件那次实验的差异（诚实说明）：课件是"训练事实×原题 2%→100%"，我们是 5%→5%。
差别在数据形态——课件用的是冷门短事实（答案是几个字），我们的是 60–160 字的财务口径描述、
里面一串 12 位金额，判分要求每个数字都对。轮数从 3 加到 6 时数字命中率 8%→13%（在动），
但完全答对仍是 5%——这类量级的事实不是 LoRA 该扛的活。

## 怎么跑

```powershell
cd ../代码
python fetch_reports_dongmi.py      # 茅台 11 份财报
python build_corpus_dongmi.py       # 切块
python gen_qa_dongmi.py             # 生成 660 组问答
python dongmi_check.py              # 抽检 + 冻结评测集
python dongmi_format.py             # 渲染成 Qwen 对话模板
python prepare_eval_context.py      # 用 A 的检索把评测上下文算好
# 训练与评测需要 GPU（见 gpu/）：
#   python gpu/train_lora_dongmi.py --backend peft --epochs 6 --rank 16
#   python gpu/eval_dongmi.py --configs finetuned,kb_finetuned
python dongmi_score.py              # 判分，出四格对照表
```
