## 一页结论的要点（详见 `一页结论.pdf`）

| 问题类型 | 结果 | 为什么 |
|---|---|---|
| 单点事实（某公司某个数字） | ✅ 8/8 全对 | 答案就在一两块里，检索能秒级命中；元数据过滤保证不串公司、不串年份 |
| 跨公司数字聚合（谁最高、谁下滑） | ❌ 基线只覆盖 2/12 家 | 答案不在任何一块里，而在十几块**之间**；窗口只有 6 块，装不下 12 家 |
| 行业级叙述（普遍面临什么、怎么应对） | ⚠️ 提到 4–5 家 | 需要"读全"，碎块检索只看到一角 |

**补救手段的对照实验**（见 `附件/全景题补救实验.md`）：top-6 → 2/12；top-60 → 3/12；
逐家检索 → 3/12；**离线抽一张跨公司指标表 → 12/12**。

## 怎么跑

```powershell
cd ../代码
python fetch_reports.py            # 下载 12 家白酒公司 2026 半年报
python fetch_reports_dongmi.py     # 下载茅台 11 份财报
python build_corpus.py             # 抽正文+表格 → 切块
python build_corpus_dongmi.py
python merge_corpus.py             # 并入同一个知识库
# 向量编码需要 GPU，见 gpu/embed_chunks.py；阿里向量与 BM25 在本机：
python build_index_ali.py
python build_bm25.py
python eval_a.py                   # 10 道题评测
python webapp.py                   # 打开 http://127.0.0.1:8000 看问答页面
```

密钥：`python save_key.py` 把 API key 写进 Windows 凭据管理器（代码里没有明文）。
